# Component Library Documentation

Welcome to the documentation for our component library! This library provides a collection of reusable components that can be used to build user interfaces in React.

## Installation

To install the component library, you can use npm or yarn:

```bash
npm install xb-onepiece-library
```

or

```bash
yarn add xb-onepiece-library
```

## Usage

To use the components in your project, you need to import them into your code. Here's an example of how to import and use a button component:

```jsx
import { Button } from 'xb-onepiece-library';

function App() {
  return (
    <div>
      <Button onClick={() => console.log('Button clicked!')}>
        Click me
      </Button>
    </div>
  );
}
```

For more detailed usage instructions and examples, please visit our [component library documentation website](https://lqr-hy.github.io/base-components/).
