# Toast 组件

`Toast` 组件用于显示简短的消息通知。

## 使用示例

```jsx
import React from 'react';
import { toast, Button } from '@xb-onepiece/components';

export default function Example() {
  const showToast = () => {
    toast({
      type: 'success',
      content: '成功'
    })
  }

  return (
    <div>
      <Button onClick={() => }/>
    </div>
  );
}
```
